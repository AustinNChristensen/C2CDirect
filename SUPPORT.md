# Support

C2CDirect Core is community-supported software. Use the public repository's issue tracker for
reproducible bugs, installation problems, and feature requests once the repository is published.
Please search existing issues first and include the C2CDirect version, deployment method, relevant
sanitized logs, and steps to reproduce.

Do not post API keys, OAuth credentials, résumés, recruiter messages, private job descriptions,
database backups, or vulnerability details in a public issue. Report security problems using the
private process in [SECURITY.md](SECURITY.md).

The future hosted edition will have a separate managed-support policy. No response-time or uptime
commitment applies to the community edition unless provided under a separate written agreement.
